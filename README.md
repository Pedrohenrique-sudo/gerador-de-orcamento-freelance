## 🧐 Sobre o Projeto
Uma ferramenta prática e elegante desenvolvida para freelancers que precisam de agilidade. O projeto permite criar orçamentos profissionais, com cálculos automáticos, e exportá-los em PDF instantaneamente.

> **Status do Projeto:** 🚀 Finalizado

---

## ✅ Funcionalidades (Checklist)
- [x] Interface Responsiva (Mobile e Desktop)
- [x] Adição dinâmica de múltiplos serviços
- [x] Cálculos automáticos de Subtotal e Total
- [x] Persistência de dados com `LocalStorage`
- [x] Exportação para PDF formatado
- [x] Sistema de remoção de itens indesejados

---

## 🛠️ Tecnologias e Ferramentas
*   **Frontend:** HTML5, CSS3 (Flexbox/Grid)
*   **Lógica:** JavaScript ES6+
*   **PDF:** [html2pdf.js](https://github.io)
*   **Ícones:** [Font Awesome](https://fontawesome.com)
