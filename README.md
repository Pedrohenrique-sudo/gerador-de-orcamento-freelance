## 📌 Visão Geral
Este projeto foi criado para simplificar o fluxo de trabalho de freelancers. Ele elimina a necessidade de planilhas complexas, permitindo que o usuário preencha dados, visualize os cálculos em tempo real e exporte um documento PDF profissional e formatado.

## ✨ Funcionalidades Principais
- [x] **Cálculos Inteligentes:** Processamento automático de subtotais e valor total.
- [x] **Persistência de Dados:** Uso de `LocalStorage` para manter as informações salvas.
- [x] **Exportação Profissional:** Integração com `html2pdf.js` para gerar arquivos PDF.
- [x] **Interface Adaptável:** Design responsivo para celulares e computadores.
