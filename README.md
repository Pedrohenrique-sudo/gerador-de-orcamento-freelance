## 📌 Visão Geral
Este projeto foi criado para simplificar o fluxo de trabalho de freelancers. Ele elimina a necessidade de planilhas complexas, permitindo que o usuário preencha dados, visualize os cálculos em tempo real e exporte um documento PDF profissional e formatado.

## ✨ Funcionalidades Principais
- [x] **Cálculos Inteligentes:** Processamento automático de subtotais e valor total com base em quantidade e preço unitário.
- [x] **Persistência de Dados:** Uso de `LocalStorage` para manter as informações do prestador salvas entre sessões.
- [x] **Exportação Profissional:** Integração com a biblioteca `html2pdf.js` para geração de documentos prontos para envio.
- [x] **Interface Adaptável:** Design responsivo focado na experiência do usuário (UX) em dispositivos móveis e desktops.

## 🛠️ Tecnologias Utilizadas
- **Linguagem Principal:** JavaScript (ES6+)
- **Estruturação e Estilo:** HTML5 & CSS3 (Flexbox/Grid)
- **Biblioteca de PDF:** [html2pdf.js](https://github.io)
- **Ícones:** Font Awesome
