## 🧐 Sobre o Projeto
Uma ferramenta prática e elegante desenvolvida para freelancers que precisam de agilidade. O projeto permite criar orçamentos profissionais, com cálculos automáticos, e exportá-los em PDF instantaneamente.

> **Status do Projeto:** 🚀 Finalizado

---

## ✅ Funcionalidades
- [x] **Interface Responsiva:** Funciona no celular e no PC.
- [x] **Dinamismo:** Adicione ou remova serviços com um clique.
- [x] **Cálculos Reais:** Soma automática de valores e subtotais.
- [x] **Persistência:** Seus dados ficam salvos via `LocalStorage`.
- [x] **Exportação PDF:** Gere o arquivo pronto para enviar.

---

## 🛠️ Tecnologias
*   **HTML5 / CSS3** (Layout moderno com Flexbox)
*   **JavaScript ES6+** (Lógica de negócios)
*   **html2pdf.js** (Geração de documentos)

---

## ⚙️ Como Executar
1. Clone o projeto: `git clone https://github.com`
2. Abra o arquivo `index.html` no seu navegador.
