# Gerador de Orçamentos para Freelancers

Projeto front-end em HTML/CSS/JS puro, com foco em layout limpo estilo SaaS e usabilidade.

## Estrutura de arquivos

- `index.html`: estrutura da interface e campos do orçamento.
- `styles.css`: tema visual, responsividade e estilos de impressão.
- `script.js`: lógica da aplicação (cálculos, linhas dinâmicas e LocalStorage).

## Funcionalidades

- Adicionar e remover linhas de serviços.
- Cálculo automático de subtotal por item e total geral.
- Desconto em porcentagem aplicado sobre o subtotal.
- Persistência de dados do freelancer (`nome`, `logo`, `contato`) no navegador.
- Botão para impressão/Geração de PDF usando recurso nativo do navegador.

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Preencha os dados do freelancer e cliente.
3. Adicione serviços e valores.
4. Clique em **Gerar PDF / Imprimir** e selecione **Salvar como PDF**.
